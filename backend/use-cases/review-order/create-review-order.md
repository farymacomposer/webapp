# Use-Case: Создать заказ

## Эндпоинт
- Метод: `POST`
- Путь: `/api/ReviewOrder/CreateReviewOrder`

## Что делает
Создает заказ на разбор трека выбранного типа (`OutOfQueue`, `Donation`, `Free`, `Charity`) и привязывает его к подходящему стриму.
Выбор стрима зависит от типа заказа и истории заказов ника.

## Входные данные
- Заголовок: `Idempotency-Key` (`Guid`), обязателен.
- Body: `CreateReviewOrderRequest`
  - `Nickname` (1..40 символов)
  - `OrderType`
  - `TrackUrl` (опционально, валидный URL)
  - `PaymentAmount` (для доната > 0)
  - `TopUpProvider` (для доната: `Donationalerts`, `Donatty`, `TwitchChannelPoints`, `Manual`)
  - `UserComment` (до 200 символов)

## Что можно
- Создать заказ любого поддерживаемого типа.
- Создать `Preorder` (если `TrackUrl` не передан) или `Pending` (если `TrackUrl` передан).
- Для донатного заказа создать пополнение и платеж в рамках создания.
- Для `Donation` и `Free`:
  - если у ника уже были заказы, заказ привязывается к ближайшему стриму типа `Donation`;
  - если заказов у ника еще не было, заказ привязывается к ближайшему доступному стриму (`Live` или будущему `Planned`).
- Для `OutOfQueue` заказ привязывается к ближайшему доступному стриму (`Live` или будущему `Planned`).
- Для `Charity` заказ создается только в активном стриме типа `Charity`.

## Что нельзя
- Передавать неподдерживаемый тип заказа.
- Для `Donation` не передавать сумму/провайдера или передавать сумму `<= 0`.
- Для `Free`, `OutOfQueue`, `Charity` передавать ненулевую сумму.
- Создать заказ без доступного подходящего стрима.
- Для `Charity` создать заказ, если нет активного благотворительного стрима.

## Условия выполнения
- Требуется роль администратора (`AuthorizeAdmins`).
- Работает идемпотентность через фильтр `[Idempotent]` в рамках пользователя, маршрута и `Idempotency-Key`.
- Пользователь из токена должен существовать.

## Результат
- `200 OK`
- Тело: `CreateReviewOrderResponse`
  - `ReviewOrder: ReviewOrderDto`

## На что влияет
- Создает заказ в БД.
- Может создавать финансовые транзакции (для `Donation`).
- Публикует событие `ReviewOrderChangedEvent` с типом `OrderCreated`.
