# Review Order Use-Cases

- `create-review-order.md` - создание заказа.
- `move-up-review-order.md` - поднятие заказа в очереди.
- `add-track-url.md` - добавление/изменение ссылки на трек.
- `take-order-in-progress.md` - взятие заказа в работу.
- `complete-review-order.md` - выполнение заказа.
- `freeze-review-order.md` - заморозка заказа.
- `unfreeze-review-order.md` - разморозка заказа.
- `cancel-review-order.md` - отмена заказа.
- `review-order-status-graph.md` - граф переходов статусов заказа.
