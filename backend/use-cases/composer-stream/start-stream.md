# Use-Case: Запустить стрим

## Эндпоинт
- Метод: `POST`
- Путь: `/api/ComposerStream/StartStream`

## Что делает
Переводит стрим из `Planned` в `Live` и фиксирует время старта (`StartedAt = UtcNow`).

## Входные данные
- Body: `StartStreamRequest`
  - `ComposerStreamId` (`long`) - идентификатор стрима.

## Что можно
- Запустить стрим в статусе `Planned`.
- Повторно вызвать запуск для уже `Live` стрима (операция идемпотентна, вернется текущий стрим без ошибок).

## Что нельзя
- Запустить несуществующий стрим.
- Запустить стрим в статусе `Completed` или `Canceled`.
- Запустить другой стрим, пока уже есть активный `Live` стрим.

## Условия выполнения
- Требуется авторизация композитора (`AuthorizeComposer`).
- Должен существовать стрим с указанным `ComposerStreamId`.

## Результат
- `200 OK`
- Тело: `StartStreamResponse`
  - `ComposerStream: ComposerStreamDto`
- После успешного старта:
  - `Status = Live`
  - `StartedAt` заполнено текущим UTC-временем

## На что влияет
- Обновляет состояние стрима в БД.
- Публикует событие `ComposerStreamChangedEvent` с типом `StreamStarted`.
