# Composer Stream Use-Cases

- `find-streams.md` - поиск стримов за период.
- `find-live-and-planned-streams.md` - текущий и запланированные стримы.
- `create-stream.md` - создание стрима.
- `start-stream.md` - запуск стрима.
- `complete-stream.md` - завершение стрима.
- `cancel-stream.md` - отмена стрима.
