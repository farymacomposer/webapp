# Use-Case: Получить список стримов за период

## Эндпоинт
- Метод: `GET`
- Путь: `/api/ComposerStream/FindStreams`

## Что делает
Возвращает список стримов, у которых `EventDate` попадает в диапазон от `DateFrom` до `DateTo` включительно.

## Входные данные
- Query-параметры:
  - `DateFrom` (`DateOnly`) - начало периода.
  - `DateTo` (`DateOnly`) - конец периода.

## Что можно
- Запрашивать любой период, где `DateFrom <= DateTo`.
- Получать как пустой список, так и список из нескольких стримов.

## Что нельзя
- Передавать период, где `DateFrom > DateTo` (ошибка валидации).

## Условия выполнения
- Авторизация не требуется.
- Период должен пройти валидацию запроса.

## Результат
- `200 OK`
- Тело: `FindStreamsResponse`
  - `Streams: IEnumerable<ComposerStreamDto>`

## На что влияет
- Только чтение данных.
- Не меняет состояние стримов.
- Не публикует событий в очереди.
